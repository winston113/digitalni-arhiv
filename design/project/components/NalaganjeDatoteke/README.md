Cona za nalaganje pogodbe in prikaz izbrane datoteke.

- `upload` je prazna cona; `is-dragging` med vlečenjem, `is-invalid` ob napaki.
- Po izbiri cono zamenja `file` z imenom, velikostjo in gumbom za odstranitev.
- Napaki: napačna vrsta datoteke, prevelika datoteka. Obe imata `field-error` pod cono.
- Na telefonu je vidno isto; vlečenje ni pogoj za uporabo.
