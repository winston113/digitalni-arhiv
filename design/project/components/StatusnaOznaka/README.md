Pokaže izračunani status pogodbe.

| Status | Razred | Ikona |
|---|---|---|
| Aktivna | `badge-active` | `circle-check` |
| Kmalu poteče | `badge-soon` | `clock` |
| Potekla | `badge-expired` | `circle-x` |
| Še ni v veljavi | `badge-future` | `circle-ellipsis` |
| Prekinjena | `badge-ended` | `ban` |

Status ima vedno ikono in besedo, barva ga samo podpira. Teh barv ne uporabljajte za okras ali kategorije.
