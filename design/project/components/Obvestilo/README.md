Sporočilo o izidu dejanja ali o stanju pogodbe.

- `notice-success` s `toast`: kratka potrditev, izgine po petih sekundah, `role="status"`.
- `notice-warning`: na strani pogodbe, ki zahteva ukrepanje.
- `notice-error`: nad obrazcem ali vsebino, ostane do odprave napake, `role="alert"`.

Sporočilo pove, kaj se je zgodilo in kaj lahko uporabnik naredi.
