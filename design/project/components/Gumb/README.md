Sproži dejanje. Na zaslonu je en sam glavni gumb.

- `btn btn-primary`: glavno dejanje zaslona.
- `btn btn-secondary`: druga dejanja.
- `btn btn-danger`: samo končna potrditev brisanja ali prekinitve v pogovornem oknu.
- `btn btn-text`: manj pomembno dejanje; `btn-text-danger` za začetek brisanja.
- `btn btn-icon`: samo ikona; obvezen `aria-label`.
- Med shranjevanjem nastavite `aria-busy="true"`, ikono zamenjajte z `loader-circle` in preprečite ponovni klik.

Napis je glagol ali jasen predmet dejanja: »Shrani pogodbo«, ne »V redu«.
